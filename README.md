# ccna-lablets

Small, self-contained CCNA lab exercises ("lablets") for hands-on practice.

## Structure

```
ccna-lablets/
├── labs/          # individual lab folders
├── topologies/    # network diagrams / config files
└── notes/         # study notes and references
```

## Getting Started

Add each lab as its own folder under `labs/` with a short README describing
the objective, topology, and expected outcome.
